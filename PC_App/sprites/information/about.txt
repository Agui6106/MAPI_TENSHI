MAPI-Tenshi Control Panel. Stable Version: 1.0

General Description:
    The MAPI-Tenshi Control Panel aims to improve remote robot control in disaster relief
    scenarios, enabling rapid responses through an intuitive IoT-powered interface.

About:
    The MAPI-Tenshi Control Panel is software dedicated to the remote control of multiple
    Tenshi Robots, available through IoT technologies, with an easy-to-use interface. It 
    enables fast and secure communication for quick deployment of Tenshi Robots in natural
    disaster scenarios, enhancing agility in life-saving actions.

System Requirements:
    - Operating System: Windows 10
    - RAM: 2GB minimum
    - Disk Space: 3 MB
    - Python 3.11.0 minimum
    - Node-RED version: v4.0.2
    - Node.js  version: v20.16.0
    - Internet connection
    - User must have a created ThingSpeak account. Create one at:
        https://thingspeak.mathworks.com/

Instalation:
    Downlaod executable at:
        link.com
    Source file aviable at GitHub:
        https://github.com/Agui6106/MAPI_TENSHI

Configurations and Setup:
    WARNING: If executing on a DIY Robot, please install the Robot Program on your device.  
             No warranty of functionality in this case!

    1. Run Node-RED on your control PC.

    2. Turn on your robot and connect to the user interface using HDMI or wireless methods
    
    3. Run the main program according to the following cases:  
        A - If downloaded from GitHub (recommended for DIY Robots): Run `main.py`.  
        B - If using the official MAPI-TENSHI robot, simply type `run` in the terminal. 

    4. The robot will ask for the host IP. Please input your PC's IP to connect to the 
       MQTT broker.  
       NOTE: Node-RED must be running!  

    5. The robot will provide you with a URL. Please copy and paste it into the login 
       interface in the "URL Stream" entry field.  

    6. Insert the remaining arguments (optional).  
        If none are selected, the system will use the following defaults:  
            Raspberry IP    - 0.0.0.1  
            ESP IP          - 0.0.0.2  
            Stream URL      - https://server-example.com  
            Robot ID        - 01  

    7. Before starting, ensure your controller is connected (Xbox and PlayStation 
       controllers are supported).  

    8. Click "Start," and the interface should now be running!

Features:
    - Real time remote control
    - Connectivity using MQTT protocols
    - Node-red interface as debugger
    - Fast location detection 
    - Connectivity with ThingSpeak claud for Matlab Data analitcs

Common Problems and Troubleshooting:  
    Problem:    No video available.  
    Solution:   Make sure to copy the URL correctly.  

    Problem:    No MQTT communication.  
    Solution:   Ensure that Node-RED is running correctly.  

    Problem:    My joystick is not detected.  
    Solution:   Make sure to connect it to a USB port on your PC. Note that wireless 
                connections are not supported.  

    Problem:    My official robot doesn't start/move.  
    Solution:   Check that the batteries are correctly inserted in the rack. If the 
                problem persists, charge your batteries.  

    Problem:    Robot failed to start the stream.  
    Solution:   Fully reboot the robot. If the problem persists, check the camera 
                connections.  

FAQ:  
    1. Can I control 2 or more robots?  
    ANS: Yes, if you have sufficient Wi-Fi bandwidth.  

    2. Do I have to pay for the use of this software?

    3. Can I run MAPI-Tenshi Control Panel multiple times?  
    ANS: Yes, you can run it as many times as your system supports.  

    4. Can the software control multiple robots at once?  
    ANS: No, but you can run the app for as many robots as you have and connect them

    5. Can I use part of your code in my own projects?

       controles de Xbox y PlayStation). 

    8. Haz clic en "Iniciar" y la interfaz debería estar en funcionamiento.

MAPI-Tenshiコントロールパネル 安定版: 1.0

概要:
MAPI-Tenshiコントロールパネルは災害救助シナリオにおいて迅速な対応を可能にする、
IoTを活用した直感的なリモートロボット制御ソフトウェアです。

詳細:
MAPI-Tenshiコントロールパネルは複数のTenshiロボットをリモート制御するための
ソフトウェアです。使いやすいインターフェースとIoT技術を活用し、災害救助シナリオ
での迅速かつ安全な通信を実現します。これにより、生命救助活動の迅速化をサポートします。

システム要件:
    OS: Windows 10
    RAM: 最低2GB
    ディスク容量: 3MB
    Python 3.11.0以上
    Node-REDバージョン: v4.0.2
    Node.jsバージョン: v20.16.0
    インターネット接続
    ThingSpeakアカウントが必要です。以下で作成してください:
    https://thingspeak.mathworks.com/

インストール:
    以下から実行ファイルをダウンロードしてください:
        link.com
    ソースコードはGitHubで利用可能:
        https://github.com/Agui6106/MAPI_TENSHI

設定とセットアップ:
    注意: DIYロボットで実行する場合、ロボットプログラムをデバイスにインストールして
          この場合、機能の保証はありません。 ください。S
    
    1. コントロールPCでNode-REDを実行します。

    2. ロボットを起動し、HDMIまたは無線接続を介してユーザーインターフェースに接続します。

    3. 以下の場合に応じてメインプログラムを実行します。
        A - GitHubからダウンロードした場合(DIYロボットに推奨): main.pyを実行してください。
        B - 公式のMAPI-TENSHIロボットを使用する場合: ターミナルでrunと入力してください。

    4. ロボットがホストIPを要求します。PCのIPを入力し、MQTTブローカーに接続してくだ
       さい。注意: Node-REDが実行中である必要があります！

    5. ロボットがURLを提供します。それをコピーし、ログイン画面の「URL Stream」欄に
       貼り付けます。
    
    6. 残りの引数を入力します(任意)。入力がない場合、システムは以下のデフォルトを使用
       します: 
            Raspberry IP    - 0.0.0.1  
            ESP IP          - 0.0.0.2  
            Stream URL      - https://server-example.com  
            Robot ID        - 01  

    7. 開始する前にコントローラーが接続されていることを確認してください(Xboxおよび
       PlayStationコントローラー対応)。

    8. 「開始」をクリックし、インターフェースが動作することを確認してください！

特徴:
